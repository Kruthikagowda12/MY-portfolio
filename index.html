About

I'm a Python developer who likes the part of software nobody sees: the endpoint that returns exactly what it promised, the query that stops being slow, the test that catches the bug before a user does. Day to day that means Django and Django REST Framework, the Frappe Framework, and PostgreSQL, Redis and AWS S3 behind them.

I came into backend work through machine learning — a diabetes-prediction pipeline in scikit-learn taught me to care about data before models — and I've kept that thread alive with LangChain and applied AI/ML alongside my engineering work. I finished my MCA at VTU with 89.9%, and I'm happiest on a team where code review is a conversation.
